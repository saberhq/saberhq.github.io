# Website UI kit

Home page of saberhq.com reworked onto the Saber HQ brand — real content from `saberhq/saberhq.github.io` (hero copy, podcast/newsletter blurbs, latest posts, about, recent news), NOT a recreation of the current Hugo Book theme. Composes `components/core/` (Button, Tag, Card, SectionHeader). Theme toggle in the top bar switches light/dark tokens.
