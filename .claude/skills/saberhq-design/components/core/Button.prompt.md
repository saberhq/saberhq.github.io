Solid-ink or hairline-outline button; use for CTAs like "Resume" or "Explore the podcast" — accent color is never a button fill.

```jsx
<Button href="/resume.pdf">Resume</Button>
<Button variant="secondary" size="sm">Read the newsletter</Button>
```

Variants: primary (solid ink, inverts in dark mode), secondary (hairline outline), ghost. Sizes md/sm. Pass `href` to render an anchor.
